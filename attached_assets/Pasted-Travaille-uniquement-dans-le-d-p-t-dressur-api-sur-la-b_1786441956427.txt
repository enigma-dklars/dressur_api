Travaille uniquement dans le dépôt dressur_api, sur la branche work_by_ai.

Objectif : finaliser le nettoyage documentaire des quatre champs de réseaux sociaux personnels supprimés de l’entité User :

- tiktok ;
- instagram ;
- facebook ;
- youtube.

Fichiers à corriger uniquement :
- assistant_ia_prompt.txt ;
- templates/public/conditions_utilisation.html.twig ;
- templates/public/politique_confidentialite.html.twig.

Consignes :

1. Dans assistant_ia_prompt.txt
   - Supprime les instructions indiquant que l’utilisateur peut renseigner, modifier, consulter ou transmettre ses URLs personnelles TikTok, Instagram, Facebook ou YouTube.
   - Supprime les exemples de données utilisateur qui correspondent à ces quatre champs.
   - Mets à jour les consignes de l’assistant afin qu’il ne propose plus ces champs dans une modification ou une réponse de profil.
   - Conserve les instructions sans rapport avec ces données personnelles.

2. Dans templates/public/conditions_utilisation.html.twig
   - Supprime ou reformule uniquement les passages qui présentent les URLs personnelles TikTok, Instagram, Facebook ou YouTube comme des informations de profil utilisateur collectées, enregistrées, modifiables ou affichées par Dressur.
   - Réécris les phrases afin qu’il ne reste pas de référence incohérente ou de formulation orpheline.
   - Ne supprime pas les mentions générales de réseaux sociaux lorsqu’elles concernent :
     - les promotions ;
     - les services commerciaux ;
     - les contenus publiés ;
     - les comptes officiels de Dressur ;
     - une plateforme externe sans lien avec les champs personnels de User.

3. Dans templates/public/politique_confidentialite.html.twig
   - Supprime ou reformule les passages indiquant que Dressur collecte, stocke, transmet ou affiche les quatre URLs personnelles de l’utilisateur.
   - Retire ces quatre champs des listes de données de profil si elles y figurent.
   - Mets à jour les paragraphes concernés avec une rédaction cohérente.
   - Ne modifie pas les mentions générales relatives aux plateformes sociales, aux contenus, aux promotions ou aux liens officiels de Dressur lorsqu’elles ne concernent pas les URLs personnelles de l’entité User.

Important :
- Ne supprime pas les comptes officiels de Dressur ou de BlueLife Tech.
- Ne supprime pas les liens YouTube des tutoriels, stories ou contenus.
- Ne supprime pas les promotions TikTok, Instagram, Facebook ou YouTube.
- Ne supprime pas le boost Facebook.
- Ne modifie aucune entité, migration, table ou endpoint API dans ce prompt.
- Ne modifie aucun autre fichier sauf si un fichier directement concerné contient une référence documentaire strictement nécessaire à la correction.

Validation obligatoire :
1. Recherche dans les trois fichiers les termes :
   - tiktok ;
   - instagram ;
   - facebook ;
   - youtube ;
   - réseaux sociaux ;
   - liens sociaux ;
   - profil social.
2. Pour chaque résultat restant, vérifie qu’il concerne bien un usage indépendant des champs personnels User.
3. Vérifie qu’aucune phrase ne prétend encore que ces quatre URLs sont enregistrées, modifiables, transmises par l’API ou affichées dans le profil utilisateur.
4. Vérifie la syntaxe Twig des deux templates.
5. Vérifie le diff complet pour confirmer que seuls les passages documentaires obsolètes ont été corrigés.
